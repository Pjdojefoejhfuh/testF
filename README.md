# NUKE BOT - NIKI EDITION

## 🚀 Installation
1. `npm install`
2. Modifier `.env` avec ton token
3. `npm start`

## 🔧 Commande
`!vnuke` - Supprime tous les salons et en crée 30 nouveaux avec le message "NUKED BY NIKI"

## ⚠️ Attention
- Le bot doit avoir la permission **Administrateur**
- Action IRREVERSIBLE !
